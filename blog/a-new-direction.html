A new direction for XQ95

17 November 2026 · The XQ95 team

XQ95 is starting work on its own system software. None of the projects below exist as finished XQ95 products yet. This post sets out what we plan to build and how we'll build it.

Two kinds of projects

Open source. The foundation of the system: Kernel, Boot, Init, Coreutils, Netstack, Package Tools, IPC, Sysmon, and the SDK. The code will be public, so anyone can read, use, and improve it.

Private. The products we build for people and organizations: Workdesk OS, Enterprise Suite, Deployment System, Security Suite, and Client Solutions.

Why build from the kernel up

When we own each layer, we decide how the whole system behaves. We can fix a problem in the layer where it starts, instead of working around it higher up. Keeping the foundation open means others can check our work and build on it.

What happens next

  • Each open-source project gets a public repository when work on it begins.
  • We'll post progress updates on this blog.
  • We'll announce release dates only when a project is ready to use.

Questions? Email contact@xq95.com.

Built from the kernel up. No personal data, no telemetry, no tracking.
