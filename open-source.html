Open source

The foundation, in the open

Nine projects make up the base of the XQ95 system. Their source code will be public, so anyone can read it, use it, and help improve it.

How the layers fit

Each layer depends on the one beneath it. The kernel and boot loader sit at the bottom; developer tools sit at the top.

XQ95 Init

Layer: System services

The first process to run. Starts system services in the right order and keeps them running.

XQ95 IPC
