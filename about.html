About XQ95

XQ95 builds system software, from the kernel up to the tools people use every day.

Our mission

Make computers that are understandable, dependable, and built for focused work.

What we build

  • An open foundation. The kernel, boot loader, init system, core tools, networking, and developer kit, published as open source.
  • Private products. Workdesk OS and our business products, built on that foundation.

Our principles

Five rules shape every product: zero unintended access pathways, comprehensive host isolation, zero data collection, client-side data sovereignty, and local-first AI processing with zero data retention.

How we work

  • Own every layer. We fix problems where they start instead of working around them.
  • Keep it light. Software should run well on modest hardware.
  • Be clear about status. We label each project as planned, in development, or released.

Where we are now

Every project on this site is planned or in development. Follow the blog for progress.

Built from the kernel up. No personal data, no telemetry, no tracking.
